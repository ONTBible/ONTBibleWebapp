# ONTBible — Webapp

Le site de La Bible ONT : ce qu'est le projet, d'où il vient, et les passages
partagés.

Sert aussi `/.well-known/apple-app-site-association`, le fichier qui autorise
l'app iOS à ouvrir les liens `ontbible.com` — aujourd'hui rendu par la Lambda,
à reprendre ici quand le site prendra la racine du domaine.
